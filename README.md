# Preethi | Portfolio Website

A responsive personal portfolio showcasing my skills, about me, and projects as a frontend and Python developer.

**Live demo:** https://preethi1909.github.io/Portfolio/

## ✨ Features

- Responsive layout for desktop, tablet and mobile
- Light and dark mode with a toggle, remembered between visits
- Smooth scrolling, active navigation highlight and scroll-in animations
- Skills section with technology icons
- Project cards with screenshots, tech tags and GitHub links
- Contact form that opens a prefilled Gmail message
- Back-to-top button

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- JavaScript (vanilla)
- [Bootstrap 5](https://getbootstrap.com/) for the navbar and form styles
- [Bootstrap Icons](https://icons.getbootstrap.com/) and [Devicon](https://devicon.dev/) for icons
- [Poppins](https://fonts.google.com/specimen/Poppins) font from Google Fonts
